# ElectroRent ⚡

Online Electronics Rental Platform frontend.

## Pages
- index.html - Home
- products.html - Product listing
- categories.html - Categories
- product-details.html - Product details
- cart.html - Rental cart
- login.html - Login
- register.html - Registration
- my-rentals.html - Rental history

## Technologies
HTML5, CSS3, JavaScript

## Run
Open `index.html` in a browser.

## Future Full-Stack Version
Connect the frontend to Java/Spring Boot, MVC layers, REST APIs, and MySQL.
